# Personal Portfolio

## Project Overview

This is my personal portfolio website where I showcase my skills, projects, professional experience, and web development work.

The portfolio is designed with a modern, responsive, and user-friendly interface.

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Node.js
* Express.js
* MongoDB
* Axios
* React Router
* React Icons

## Main Features

* Responsive portfolio design
* About Me section
* Skills section
* Personal Projects
* Professional Projects
* Project folders
* Project details
* GitHub and live project links
* Admin project management
* Contact information
* Modern animations and UI

## Dependencies

* React
* React Router DOM
* Axios
* React Icons
* React Markdown
* Tailwind CSS
* Express
* Mongoose
* JSON Web Token
* Cloudinary
* Other required dependencies are listed in `package.json`.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/abdurrahmantushar/abdurPortFolio.git
```

### 2. Go to the project folder

```bash
cd abdurPortFolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will run on the local development server.
